# 放你的原始素材

这个目录是**你和自己的宠物**打交道的地方。放照片，跑一条命令，就能做出属于你的桌宠。

```
source/
├── origin_images/     原始照片（本条说明针对这里）
└── origin_audios/     原始音频，可以先空着
```

## 命名规则

```
<状态>_<序号>.png
```

- 序号从 1 开始，同一状态有几张就编到几号
- 只有一张时可以省序号（`idle.png`），但**建议统一带序号**，以后加图不用改名
- 支持 PNG / JPG，背景随便，预处理会自动抠掉

## 需要哪些状态

| 状态 | 中文 | 建议张数 |
|---|---|---|
| `idle` | 静息 | 3–4 |
| `touch` | 被撸 | 4–6 |
| `scratch` | 不高兴 | 2–3 |
| `play` | 自己找事做 | 4–6 |
| `sleep` | 睡觉 | 3–4 |
| `dragging` | 被拎起来 | 2 |
| `menu` | 端正坐好 | 1–2 |
| `startled` | 惊醒 | 1–2 |
| `landed` | 落地 | 1–2 |

另外还有两个非状态素材：

| 用途 | 文件名 |
|---|---|
| 应用图标 / 面板 logo | `logo_1.png` |
| 菜单栏剪影 | `menubar_1.png`（**用猫的侧面/正面照也行**，预处理会按 alpha 通道做成纯黑剪影） |

完整规格见 [doc/PRD/PRD.md](../doc/PRD/PRD.md)。

## 拍照片的小建议

**① 背景请用纯色。**
预处理用的是 rembg/u2net 语义分割，**不是大模型**——它擅长"一个主体 + 干净的背景"。
白墙、纯色地板、纯色沙发套上拍，边缘最干净；花纹墙纸、堆满杂物的房间、画面里有别的宠物或人，
容易抠出毛边或者把别的东西留下来，而且没有"重试"按钮。这一条最省事也最有效。

**② 同一个机位、同一套灯光。**
不同状态之间切换时，猫的体型和地面线要能对上，否则会"跳"。

**③ 同一状态的多张图，只改表情和姿态，别把猫挪位置。**

**④ 照片的方向就是最终效果，程序不会替你转。**

桌宠完全按你给的图来用：图里猫头朝哪边，桌面上就朝哪边；图是竖着的，它就竖着显示。
预处理只做三件事——去背景、裁到猫的外框、缩放对齐——**不会旋转、不会翻转**。

所以：

- 猫头朝下、朝侧边、身体斜着——**都会被原样保留**。如果你的猫就爱那么躺着，那正是想要的效果
- 但如果是**手机导出时方向没转正**、或者拍的时候手握歪了，请在图片工具里先转正再放进来
- 转正的标准很简单：**在 Finder / 预览里看着正常，桌面上就正常**

> 这么做是刻意的：不做自动纠正，就不存在"程序猜错了把你摆好的姿势转歪"。
> 你看到的，就是桌宠呈现的。

## 跑预处理

```bash
pip install pillow rembg
python3 code/prepare/cutout.py
```

处理结果会写到 `code/pet_images/`，同时生成一张 QA 总览图（`code/build/out/qa_sheet.png`），
用眼睛扫一遍就能看出哪张抠坏了。
