# PopoHere 使用说明

一只会自己待着、走动、睡觉的桌面猫。原生 macOS 应用，**不用装 Python，也没有任何第三方依赖**，
二进制不到 1MB，启动半秒内到位。

> 猫的原型是真实的 british shorthair，名字叫 Popo。

---

## 一、安装

**系统要求**：macOS 11（Big Sur）及以上，Intel 和 Apple 芯片都支持。

推荐做法：把 `PopoHere.app` 拖进「应用程序」文件夹，之后就能从启动台里找它。
只想尝鲜的话，就地双击也能用。

### 第一次打开时 macOS 可能会拦

因为这个应用没有向苹果付费签名（个人小工具没必要），系统第一次会提示：

> “PopoHere” 无法打开，因为来自身份不明的开发者。

这不是中毒，是 macOS 对所有未签名应用的统一提示。**绕过一次就好，之后永远正常**：

1. **右键**（或按住 Control 再点）`PopoHere.app` 图标
2. 选「**打开**」
3. 弹出的对话框里再点「**打开**」

嫌两步麻烦的话，也可以双击同目录的 `启动 PopoHere.command`，它会自动清掉这个标记再启动
（这个脚本文件本身第一次同样可能需要右键打开）。

或者在一行命令里解决（终端里粘贴执行）：

```bash
xattr -dr com.apple.quarantine ~/Downloads/PopoHere/PopoHere.app
```

## 二、怎么和它玩

| 你想做的事 | 怎么操作 |
|---|---|
| 换地方 / 把它抱起来 | 按住猫**拖动**，松手它会自己落地站好 |
| 撸它 | 在猫身上点一下；**连着猛点 10 下**它会翻脸挠你（状态面板能看到计数） |
| 叫醒它 | 它睡着时，随便戳一下就会惊醒 |

**静置 5 秒以上**，它会自己溜达或者趴下睡觉——它是有脾气的，不是 PPT。

### 菜单栏

应用没有 Dock 图标，一切都在屏幕右上角菜单栏里（找不到就是被别的图标挤走了，往左拖拖看）：

- 隐藏 / 显示 Popo —— 藏起来不是退出，点一下就回来
- 显示 / 隐藏桌宠状态 —— 右下角那块状态面板
- 大小 —— 160 / 220 / 300 / 380 px 四档，**选完会记住**
- 定时提醒 / 待办清单
- 退出

**位置也会记住**：下次打开，它就在你上次放的地方。

### 定时提醒

右键猫 →「定时提醒」。三条预置：**摸鱼 25 分钟 / 喝水 45 分钟 / 久坐拉伸 60 分钟**。

- 点「+ / −」调时间（1 → 5 → 10 → 15…）
- 右边的 **一次 / 间隔** 选提醒方式：
  - **一次**（默认）：响过就结束，开关自动关掉
  - **间隔**：按你设的间隔一直循环，直到你自己关掉
- 左边的开关是这条提醒的总开关

到点后，**屏幕右上角**会弹出一块小面板：

```
摸鱼结束，接着干活~（7s）
            [ 确认 ]
```

- 点「确认」立刻关掉；不理它，**10 秒后也会自己消失**
- 括号里是倒计时，每秒变一次
- **把猫藏起来也照样提醒**——它不依赖猫，也不依赖声音
- 几条同时到点会**叠在一起**，先关哪条由你决定

## 三、常见问题

**猫不见了？**
大概率是被你隐藏了。看菜单栏里是不是显示「显示 Popo」——是的话点一下。

**想彻底关掉？**
菜单栏 → 「退出」。顺便说一句，**隐藏不等于退出**，隐藏时它还在后台待命。

**它能联网吗？会上传我的什么吗？**
完全不会。整个应用没有一行网络代码，也没读取你的任何文件。就是一个浮在你桌面上
的透明窗口，里面跑着一段画猫的网页代码。

**为什么每次进入同一个状态，姿势好像不太一样？**
同一状态有多张素材时会**随机抽一张并锁定**，离开再进来才换。这是故意的——
猫本来就不会一直保持同一个姿势。
