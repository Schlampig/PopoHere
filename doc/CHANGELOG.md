# 更新日志

## v2.0 — 2026-10-31（开发中）

**状态机重做**
- 状态从 10 个收到 **7 个常规 + 2 个过渡**：`pet_head` + `pet_paw` 合并为 `touch`，`walk` 改为 `play`
- 命中区合并为单一 `body`：整只猫都是"撸它"，不再分头/脚
- 新增**连撸计数**：连续 10 次触摸翻脸（`touch_scratch_threshold`），冷却 6 秒
- `touch` 播放中继续点击会重播并累计连击（否则连点 10 下只会记 1 下）
- 静息 5 秒后按 **35% 去玩 / 65% 去睡** 分流，睡觉概率更高
- 菜单状态兜底从 2 秒延长到 8 秒（v2.0 是真菜单）

**素材**
- 命名统一为 `<状态>_<序号>.png`，同状态多张随机抽
- 新增 `build_theme.py`：扫描文件名自动生成 `theme.json`，用户不写 JSON
- 新增 `make_placeholder_assets.py`：研发期占位素材（正式素材到位后删除）
- 构建时按内容去重贴图，31 个引用只内联 7 张图

**菜单**
- 三入口：菜单栏图标（原生 NSMenu）、右键桌宠（玻璃面板）、状态面板
- 玻璃面板：NSVisualEffectView 真毛玻璃 + CSS 圆角/描边/阴影，深灰配色 + 猫眼绿点缀
- 状态面板从属于桌宠：隐藏桌宠时面板收起、菜单项置灰，重新显示时按记录恢复
- 新增 `func_reminder` 定时提醒（番茄钟/喝水/久坐，可调 1–180 分钟）
- 新增 `func_checklist` 待办清单（10 条上限、每条 50 字、可勾选、一键清空）
- 开机自启（LaunchAgent）

**v2.0 修复轮（用户首轮试用反馈）**
- 修复面板「返回」按钮无响应：`.back` 不在点击选择器里，事件被直接丢弃
- 修复右/下侧玻璃边缘缺失：面板尺寸量的是内容盒（不含 12px 留白），窗口比内容大一圈 → 改为内容填满窗口 + 窗口阴影 + 毛玻璃层圆角裁切
- 状态面板默认不自动打开；标题栏新增「✕ 隐藏」按钮
- 状态面板改为紧贴屏幕右下角（右边缘 = 屏宽、底边 = 屏高），尺寸变化后重新吸附；用户拖动后解除吸附
- 菜单开着时不再自动入睡（兜底超时 8s → 120s），点猫可直接收起菜单
- `menu` 状态不再吞掉点击（原先 `pressStart` 直接 return，导致关掉面板后第一下没反应）
- 一并修掉：隐藏桌宠时残留的菜单面板、动作执行后勾选状态不刷新

**v2.0 修复轮 2（菜单与状态绑定）**
- 菜单状态改为由外壳**唯一驱动**：面板显示 → `App.menuOpened()`，面板收起 → `App.menuClosed()`。
  原先 JS 右键时自己 `openMenu()`，而面板是原生弹的，两边各管一半，面板开着猫却会自己回到 idle → play/sleep
- 右键改为切换语义：菜单已开时再右键即收起
- 菜单底部新增「关闭菜单」（快捷键 esc），关闭后猫回到 idle
- 去掉 `menu.js` 里重复的 open 标志，避免状态双写

**v2.0 第二轮反馈（提醒叠放 / 摸鱼 / 一次·间隔）（2026-11-01）**

- 新增 `code/test/reminder_store_test.m`（16 条：默认值 / 一次性 / 间隔 / 时间阶梯 / 数据迁移）
- README 重做成 GitHub 看板：头图、徽章、玩法表、DIY 四步；英文版在 `doc/README_en.md`

**v2.0 修复轮 3（菜单/预览契约、连点翻脸）**
- 所有"播完"收敛到唯一出口 `_rest()`：**菜单面板还开着 → menu，否则 idle**。
  状态面板里预览状态后，不再"菜单还开着、猫已经在 idle 起步"
- `menuOpen` 只由面板 `show` / `hide` 回调写入；离开 menu 时外壳同步收起面板，
  不再依赖"面板失焦自己隐藏"（点猫时状态先走、面板留着的情况）
- 状态面板点状态名改为 `preview()`：只演一遍、不写连撸计数；没有 duration 的状态演
  `preview_duration_sec`（6s）后收尾
- 连点不翻脸的三层修复：
  1. `click_max_drift_px` 5 → **12**（与外壳 `kDragThreshold` 对齐）。5px 时连点的手抖
     会被判成拖拽，每一下都 `dragging → landed → idle`，计数永远 0
  2. `startled` / `landed` 里的点击也计数，不再被过渡动画吃掉
  3. 达到阈值**当场**转 `scratch`，不等 touch 播完（越使劲点越看不到结果的死循环）
- 状态面板底部新增「连撸 N/10」实时计数，让翻脸机制可预期
- 暂停中点击会弹「已暂停互动」提示（此前表现为"点了没反应"）
- 新增 `code/test/click_mash_test.py`（9 条，跑真实产物 + DOM 事件）
