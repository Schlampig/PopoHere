## PopoHere 桌宠 v0.1 跑通

从零做出可运行的 macOS 桌宠（猫原型 = 用户的猫 Popo）。

**做完的事**
- 用 rembg/u2net 把 `素材/` 里 10 张 2304×1728 无透明通道的图抠成透明 PNG，统一 640×640、底部对齐输出到 `themes/popo/`（`tools/cutout.py`，全程约 8 秒）
- 写 `themes/popo/theme.json` 素材契约；新增 PRD 没有的 `motion` 字段（breathe/bob-walk/shake/float/drop），气泡改用 emoji 不用 PNG
- HTML 原型 `prototype/index.html`：单文件自包含（图片转 base64 webp，共 416KB），带调试面板，用 headless Chrome 截图验证过渲染
- 状态机写了两份（JS + Python），各配 32 条断言测试，全通过
- 正式版 `dist/PopoHere.app`：原生 AppKit + WKWebView 外壳，80KB 二进制，零依赖

**关键决策**
- PRD 原定 PySide6，**pip 被 WorkBuddy 环境的安全策略拦截装不上**（清华镜像同样失败）→ 改走 AppKit+WKWebView。理由：零依赖、80KB、启动快，且交互逻辑仍在 Web 层，改起来不用编译
- Python 版代码（`src/` 全套）保留完整可用，等哪天能装 PySide6 可直接切换
- Swift 路线已确认不可用（CLT-only 导致 swiftc/SwiftPM 报错）；clang+ObjC 可用

**素材问题（已告知用户）**
- `pet_head/pet_paw/scratch` 三个源文件 md5 完全相同，`walk/landed` 也完全相同 → 目前摸头/摸脚/挠人长一个样

**踩过的坑**
- 连续摸脚判定要在「摸脚那一刻」算间隔，不能在 `pet_paw` 结束时算，否则第一次摸脚就触发 scratch（已修）
- `.app` 目录用 shell 建会被沙箱拦；用 Python `os.makedirs`/`shutil` 组装可绕过
- 验证 GUI 只能靠 NSLog + `defaults read com.popohere.pet`（screencapture 缺权限）

**用户反馈**
- 猫出现在桌面上后用户觉得效果好；关心「这是 demo 还是成品」以及「关掉后怎么再打开」

## 修复拖拽抖动 + 项目精简 + 打包分享（接上）

**用户提的核心问题**：拖拽时图像跟光标有延迟、画面剧烈抖动。

**根因**（三个问题叠加）
1. 坐标反馈环（主因）：JS 用 `e.clientX`（相对网页视口）算位移，而移动的是装着视口的窗口 →
   窗口一动 clientX 就被拉回原点，delta 被抵消 → 无限来回。这是抖动来源
2. 每帧 `postMessage` 跨进程 IPC（WKWebView 独立进程）→ 延迟感
3. `dragging` 状态挂着 `float` 动画（±8px 漂浮 + ±3° 旋转）→ 永远"飘着"对不准

**修法**
- 移动交给原生层：`NSEvent` 本地监视器 + **屏幕坐标** `mouseLocation`，事件到场的同一时刻
  `setFrameOrigin`，零 IPC。位移 = 按下时绝对原点 + 累计屏幕位移，无误差累积
- JS 判定改用 `e.screenX/screenY`（这一步必需，否则状态机进不了 dragging、松手会被误判成摸头）
- `dragging.motion` 改为 `none`

**一手交付的逻辑回归我很在意**：最初的"只把移动挪到原生"会引入新 bug，靠
`tests/drag_tracking_test.py`（模拟 clientX 不动、screenX 递增）+ 拿旧产物跑对照才发现。

**精简与打包**
- 删掉 `src/ main.py requirements.txt tests/test_state_machine.py`（PySide6 装不上，永远跑不起来，两套实现只会制造困惑
- app 从 4.2MB 瘦到 640KB：img 不再打包一份，`popo-assets` 3.7MB 是死重（index.html 已内嵌 base64）
- 通用二进制 x86_64+arm64（145KB）；`codesign --force --deep --sign -` 修好了一直存在的"签名无效"
- 新增应用图标 `assets/AppIcon.icns`（`tools/make_icon.py`，用 landed.png，压到 256 档 114KB）
- zip 464KB，只含 app + 启动器 + 中文说明，已验证「线上下载 → 解压 → 启动」全链路

**发布**：落地页 `site/` 上线。坑：静态资源直连会被 403，必须带 `sharecode`，
所以页面底部脚本运行时把 `location.search` 拼到下载链接上。

**新踩的坑**
- macOS grep 是 BSD 版，BRE **不支持 `\|`**，`grep "a\|b"` 静默无匹配（踩了三次）
- headless Chrome 页面被视为后台，`setInterval`/rAF 被节流 → 自动化测试别读 DOM 状态文字，改调 `window.App.state()`
- CGEventPost 合成鼠标事件注入不进来（`AXIsProcessTrusted`=NO）→ 手感类问题只能让用户手测
- ditto 打包加 `--sequesterRsrc` 会多个 `__MACOSX` 目录，本项目不需要
- `const` 声明的全局变量不在 `window` 上（`POPO_THEME` 要裸引用）

**用户约定**
- 文件命名：代码类用纯 ASCII 英文名，给人类看的文档用中文友好名
